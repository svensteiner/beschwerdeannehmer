# Lokal ausgelieferte Schriften

Figtree und Fraunces stammen aus den unveränderten npm-Paketen
`@fontsource-variable/figtree@5.3.0` und `@fontsource-variable/fraunces@5.3.0`.
Die jeweiligen SIL Open Font License 1.1 liegt im Unterordner als `LICENSE`.
Dateien wurden am 12.09.2026 übernommen; keine Installation als Laufzeitabhängigkeit.

Figtree verwendet die Gewichtsachse, Fraunces die Standardachsen Gewicht und
optische Größe. Normale und kursive Varianten sowie die zugehörigen
Zeichenbereiche werden durch die unveränderten Paket-CSS-Dateien geladen.
Alle Schriftanfragen bleiben auf dem Silvia-Server; Google Fonts ist dafür
zur Laufzeit nicht erforderlich. Dies ist keine Aussage über andere Datenwege.
